# Лендинг marsezh.ai — два макета

| версия | ссылка | файл |
|---|---|---|
| **Светлая** (stackbyte + Behance, циан) | https://claude.ai/code/artifact/0d077880-ac7e-4fa3-aa40-d19b2046a653 | `index.html` |
| **Тёмная** (по структуре Behance, терракота #D68A6B) | https://claude.ai/code/artifact/c3c18caa-a76f-4289-847d-7e14e01645bb | `index-dark.html` |

Обе страницы приватные — доступ открывается кнопкой **Share** в правом верхнем углу.
Локальные `index*.html` самодостаточны: все обложки вшиты внутрь (base64), интернет
нужен только для шрифтов Google Fonts. Открываются двойным кликом.

## Файлы
| файл | что это |
|---|---|
| `index.html` / `index-dark.html` | собранные макеты |
| `artifact.html` / `artifact-dark.html` | те же страницы для публикации ссылкой |
| `template.html` / `template-dark.html` | исходники разметки и стилей, без картинок |
| `build.py` / `build-dark.py` | сборщики: вшивают обложки из `assets/` в шаблоны |
| `imgutil.py` | обрезка чёрных полос и кадрирование обложек |
| `assets/` | реальные обложки роликов и аватары из Instagram / TikTok |

## Ссылка на гугл-форму
Кнопка «Заполнить заявку» в первом экране тёмной версии пока ведёт на заглушку.
Реальный адрес задаётся одной строкой в `build-dark.py`:

```
FORM_URL = "https://forms.gle/..."
```
После замены — пересобрать.

## Пересборка после правок
```
python3 build.py && python3 build-dark.py
```
Чтобы обновить страницы по тем же ссылкам, попроси меня опубликовать
`artifact.html` и `artifact-dark.html` заново.

## Локальный предпросмотр
```
python3 -m http.server 8123
```
Дальше открыть http://127.0.0.1:8123/index.html или /index-dark.html

## Дизайн тёмной версии
Собрана по структуре референса Behance «Personal Website» (Vadym Oliinyk):

* шрифт Manrope, фон #060606, белый текст, заголовки с серой второй половиной;
* первый экран: логотип, меню и иконки соцсетей в шапке, крупный заголовок и
  белая пилюля-кнопка слева, портрет из темноты по центру, зелёная точка
  «Открыт к сотрудничеству» и стеклянная визитка с тремя цифрами справа снизу,
  ряд из трёх обложек слева снизу;
* «О себе» дополнено полосой из четырёх шагов пайплайна и бегущей строкой —
  они разбивают длинные тёмные паузы между блоками;
* фирменная полоса между «О себе» и услугами: контурное «marsezh» во всю
  ширину с прозрачностью 20 %, поверх него идёт бегущая строка;
* услуги — три карточки одинаковой высоты;
* достижения — нумерованные строки; портфолио — шесть работ с пилюлей
  «Смотреть», как Selected Work в референсе;
* центрированное заявление с акцентной второй строкой и финальный блок
  с карточкой контактов и полосой из трёх утверждений в подвале;
* у всех секций одинаковый вертикальный отступ 56 px, без разделительных линий;
* меню в шапке выровнено ровно по центру страницы, соцсети — посередине между
  меню и подписью справа (позиция считается скриптом при загрузке и ресайзе);
* логотип латиницей — Marsezh.

Единственный акцент — терракота #D68A6B, снятая пипеткой с его аватарки и
обложек хайлайтов. Ею окрашены логотип, иконки соцсетей, акцентные строки
заголовков, цифры достижений и свечение за портретом. Страница осознанно
одноцветная — светлой темы у неё нет.

Портрет для первого экрана — кадр из ролика @marsezh.ai (тёмная комната,
тёплая лампа). `imgutil.portrait()` вписывает его в чёрное поле, приглушает
яркость и гасит периферию виньеткой ровно в #060606, поэтому фотография
«выплывает» из темноты без видимой рамки — как вырезанный портрет в референсе.

## Что реальное, а что — черновик
**Реальные цифры** (открытая статистика профилей на 01.09.2026): просмотры,
подписчики, лайки, комментарии, репосты, названия и обложки роликов.

**Черновик, требует подтверждения у Марсэжа:** описания трёх услуг, сроки
(«3—7 дней»), формулировки в блоке «Кто я», подписи в футере карточек услуг.
